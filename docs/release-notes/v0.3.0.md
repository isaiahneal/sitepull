# Sitepull v0.3.0

Sitepull 0.3.0 expands the native desktop release to Intel Macs and two non-Ubuntu Linux distributions without weakening Electron's sandbox or treating one WebKit build as universally portable.

## Platform coverage

- **macOS 15+ Apple silicon (arm64):** versioned DMG and ZIP
- **macOS 15+ Intel (x64):** versioned DMG and ZIP
- **Ubuntu 24.04 x64:** distribution-matched DEB
- **Debian 12 x64:** distribution-matched DEB
- **Debian 13 x64:** distribution-matched DEB
- **Windows x64:** Squirrel Setup executable and ZIP

The two macOS artifacts are built on separate native GitHub runners. Each embeds the Playwright WebKit runtime for its own architecture; the release does not disguise architecture-specific browser frameworks as a universal application.

Each Linux target is also built separately. The Ubuntu 24.04, Debian 12, and Debian 13 packages have unique Debian revisions, dependencies, filenames, and embedded WebKit binaries. This prevents an Ubuntu package from being presented as Debian-compatible merely because both systems accept the DEB format.

## Release integrity

The distribution workflow now requires an exact eleven-file native asset manifest. A missing, extra, or duplicate platform artifact stops the release before checksum generation. The workflow then creates and re-verifies `SHA256SUMS.txt` and records Sigstore-backed GitHub build-provenance attestations for every native asset and the checksum manifest.

Both macOS jobs run the full packaged application smoke test and verify the native architecture of Electron and the embedded WebKit binary with the platform toolchain. They also validate hardened Electron fuses, the ad-hoc bundle's internal signature consistency, packaged WebKit launch, preload/IPC behavior, and renderer startup.

The Ubuntu DEB is installed and smoke-tested on its native runner, then independently clean-installed in a pinned Ubuntu container for its package and dependency audit. Each Debian DEB is clean-installed in its matching pinned distribution container, audited, and smoke-tested as an unprivileged user. Across those gates, Sitepull verifies package name, version and architecture, dependency resolution, executable layout, Electron's root-owned mode-`4755` sandbox helper, the GTK and WPE WebKit dependency closures, packaged WebKit, and the Electron renderer with the sandbox enabled.

Verify a downloaded artifact with GitHub CLI:

```bash
gh attestation verify ./Sitepull-0.3.0-arm64.dmg \
  --repo isaiahneal/sitepull \
  --signer-workflow isaiahneal/sitepull/.github/workflows/distribution.yml
```

Build provenance does not replace publisher identity. These community artifacts are not signed with Apple Developer ID or Microsoft Authenticode, macOS hardened runtime and notarization remain unconfigured, and Linux packages are not distributed through a signed repository.

## Compatibility and boundaries

- Existing `v0.1.0` and `v0.2.0` captures and history remain readable.
- Use the DEB whose filename names the installed distribution. Debian 12 and Debian 13 require different system-library generations.
- A generic Linux ZIP remains intentionally absent because it cannot install Electron's setuid sandbox helper with root ownership and mode `4755`.
- RPM/Fedora and Alpine/musl artifacts remain out of scope for this release because Playwright 1.62.1 does not provide matching WebKit runtime builds for those platforms.
- Sitepull continues to capture public browser-delivered output only. It does not recover private source repositories or bypass authentication, CAPTCHAs, paywalls, anti-bot controls, or private-network restrictions.

## Install

Download the artifact for your exact platform from this release, or install the global CLI from source:

```bash
pnpm install:cli-global
sitepull --version
sitepull pull example.com --headless --ai-pack --zip
```

The CLI and generated capture metadata both report Sitepull `0.3.0`.
