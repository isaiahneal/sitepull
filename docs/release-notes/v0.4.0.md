# Sitepull v0.4.0

Sitepull 0.4.0 adds honest native headless coverage for Fedora 44 and Alpine 3.24 while keeping the existing WebKit desktop builds for macOS, Ubuntu, Debian, and Windows.

Versioned per-user CLI installs are also physically isolated from pnpm's workspace deployment and kept immutable by version. Rebuilding or removing a checkout can no longer mutate an installed version, while an atomic command cutover leaves the previous global `sitepull` command intact if an upgrade fails.

## Fedora and Alpine

- **Fedora 44 x64:** provenance-attested native RPM, installed globally as `/usr/bin/sitepull`
- **Alpine 3.24 x64:** native APK plus a release-specific APK public key, installed globally as `/usr/bin/sitepull`

Both packages use their distribution-maintained Chromium headless shell, default to Chromium, and deliberately reject other rendering engines and `--headed`. Fedora installs `/usr/lib64/chromium-browser/headless_shell`; Alpine installs `/usr/bin/chromium-headless-shell`. The release gates assemble each native package on its named distribution, clean-install it, verify package metadata and global command resolution, then run a real one-page capture as an unprivileged user. Fedora also executes and rejects any native executable in the pinned Linux x64 production closure before RPM construction.

Before the live capture, each native gate requires the renderer process to add its own seccomp filter beyond the outer build container, enable the no-new-privileges boundary, and enter isolated PID, network, and user namespaces. The GPU process must add its own seccomp filter too. These packages also disable Chromium's GL implementation and 3D software rasterizer, then filter Playwright's unsafe SwiftShader opt-in. Alpine currently installs `chromium-swiftshader` as a dependency of its headless shell, but Sitepull does not select it at runtime and the gate rejects any SwiftShader/ANGLE process argument. DOM, CSS, Canvas 2D, and screenshots remain supported; WebGL is intentionally unavailable in the Fedora and Alpine CLI packages so arbitrary captured pages do not enter Chromium's lower-security SwiftShader path. The packages remain strictly headless rather than disabling any browser sandbox layer.

They are CLI packages rather than Electron desktop packages. Official Electron and Playwright WebKit Linux binaries require glibc and cannot run natively on Alpine/musl. On Fedora 44, Playwright's Ubuntu WebKit fallback requires incompatible ICU, JPEG, and media-library ABIs. Using Fedora and Alpine's maintained Chromium headless-shell packages preserves a native, updateable browser and avoids claiming unsupported WebKit fidelity.

## Install

Fedora 44:

```bash
sudo dnf install ./sitepull-cli-0.4.0-1.fc44.x86_64.rpm
sitepull --version
sitepull pull example.com --headless --ai-pack --zip
```

Alpine 3.24:

```bash
install -m 0644 sitepull-alpine-v0.4.0.rsa.pub /etc/apk/keys/
apk add ./sitepull-cli-0.4.0-r0.apk
```

Run those two install commands from a root shell (`su -`, or `doas` when configured), then use Sitepull as your regular user:

```bash
sitepull --version
sitepull pull example.com --headless --ai-pack --zip
```

The Alpine key is generated for this release and published beside the APK. Verify both against `SHA256SUMS.txt` and GitHub's build-provenance attestations before installing them. It is not a persistent distribution repository key.

## Full platform coverage

- **macOS 15+ Apple silicon (arm64):** versioned DMG and ZIP desktop packages
- **macOS 15+ Intel (x64):** versioned DMG and ZIP desktop packages
- **Ubuntu 24.04 x64:** distribution-matched desktop DEB
- **Debian 12 x64:** distribution-matched desktop DEB
- **Debian 13 x64:** distribution-matched desktop DEB
- **Fedora 44 x64:** native headless CLI RPM
- **Alpine 3.24 x64:** native headless CLI APK and release public key
- **Windows x64:** Squirrel Setup executable and desktop ZIP

The release workflow requires the exact fourteen-file native/package asset set, generates and re-verifies `SHA256SUMS.txt`, compares the final GitHub asset names and digests byte-for-byte, and records Sigstore-backed GitHub build-provenance attestations before publication.

Verify a downloaded artifact with GitHub CLI:

```bash
gh attestation verify ./sitepull-cli-0.4.0-1.fc44.x86_64.rpm \
  --repo isaiahneal/sitepull \
  --signer-workflow isaiahneal/sitepull/.github/workflows/distribution.yml
```

These community artifacts are not signed with Apple Developer ID or Microsoft Authenticode and are not distributed through a persistent signed Linux repository. GitHub attestations establish the source workflow and exact bytes; they do not replace operating-system publisher identity.

The CLI and generated capture metadata report Sitepull `0.4.0`.
