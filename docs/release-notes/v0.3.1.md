# Sitepull v0.3.1

Sitepull 0.3.1 is the integrity-corrected platform release for Intel Macs, Apple-silicon Macs, Ubuntu 24.04, Debian 12, Debian 13, and Windows.

## What changed

GitHub normalizes `~` to `.` in uploaded release asset names. The `v0.3.0` DEB bytes and hashes were correct, but its checksum manifest retained the three pre-upload filenames. This patch canonicalizes Linux release filenames before the exact asset check, checksum generation, and provenance attestation, so the manifest names exactly what GitHub serves.

The DEBs keep distribution-specific internal versions—`0.3.1-1~ubuntu24.04`, `0.3.1-1~debian12`, and `0.3.1-1~debian13`—while their downloadable asset names use the GitHub-safe dotted form.

## Platform coverage

- **macOS 15+ Apple silicon (arm64):** versioned DMG and ZIP
- **macOS 15+ Intel (x64):** versioned DMG and ZIP
- **Ubuntu 24.04 x64:** distribution-matched DEB
- **Debian 12 x64:** distribution-matched DEB
- **Debian 13 x64:** distribution-matched DEB
- **Windows x64:** Squirrel Setup executable and ZIP

Every native artifact is rebuilt from this tag. The distribution workflow verifies native architecture, packaged WebKit, Electron fuses and sandboxing, installer identity, dependency closures, preload/IPC behavior, and renderer startup as appropriate for each platform. It then requires the exact eleven-file native manifest, creates and re-verifies `SHA256SUMS.txt`, and records Sigstore-backed GitHub build-provenance attestations before publication.

Verify the manifest after downloading it with the release assets:

```bash
sha256sum --check --strict SHA256SUMS.txt
```

Verify provenance with GitHub CLI:

```bash
gh attestation verify ./Sitepull-0.3.1-arm64.dmg \
  --repo isaiahneal/sitepull \
  --signer-workflow isaiahneal/sitepull/.github/workflows/distribution.yml
```

These community artifacts are not signed with Apple Developer ID or Microsoft Authenticode, macOS hardened runtime and notarization remain unconfigured, and Linux packages are not distributed through a signed repository.

## Install

Download the artifact for your exact platform from this release, or install the global CLI from source:

```bash
pnpm install:cli-global
sitepull --version
sitepull pull example.com --headless --ai-pack --zip
```

The CLI and generated capture metadata both report Sitepull `0.3.1`.
