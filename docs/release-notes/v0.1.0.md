# Sitepull v0.1.0

Sitepull's first public release turns a website into a structured, inspectable design reference through either the native desktop app or the shared headless CLI.

## Highlights

- Rendered, bounded same-origin crawling with Playwright WebKit by default
- Intelligent bare-host input: HTTPS first, then HTTP only when inferred HTTPS cannot connect
- Desktop and mobile screenshots, rendered DOM summaries, captured browser-delivered resources, design-token analysis, and repeated component candidates
- Compact AI Pack and complete Full Capture ZIP exports
- Hardened Electron renderer isolation and narrow, schema-validated IPC
- Headless-by-default `sitepull` CLI with an explicit `--headless` flag for automation
- Native macOS arm64, Linux x64, and Windows x64 packages built on matching GitHub-hosted runners

## Install

Download the package for your platform below. These community artifacts are not signed with Apple Developer ID, Microsoft Authenticode, or a Linux package repository key; review the README's distribution-trust section before installation.

Source users can install the global CLI with `pnpm install:cli-global`, then run:

```bash
sitepull pull example.com --headless --ai-pack --zip
```

Use `SHA256SUMS.txt` to verify downloaded assets.
